# Subjugated Dialectics — Viewer · Game · C.D. kit

- **Viewer** (this folder): scan a Subjugated Dialectics QR code, or open the page with a replay code after `#`:

```
https://xeroxgate77.github.io/engine77/#SD6.industrial.p.3.0..68c32c01234c
```

The viewer rebuilds the piece from its code with the same engine that played it, beat by beat.
It shows **AUTHENTIC** only when the rebuilt game's log hash matches the code. SD7 codes (games played on an era pack)
open only when that exact era pack ships with the viewer.

- **Game** (`play/`): https://xeroxgate77.github.io/engine77/play/ — Audience, Persona or System, or AUTO MODE (the AI plays
  every seat). Public build: finished runs give a replay code that opens in the viewer. Players may extract a piece
  (downloaded as a .zip); it carries no creator signature and is labelled "Extracted by: player" — not a creator edition.
- **C.D. kit** (`cd/`): the Conjugated Dialectics kit and Studio for AIs.

The viewer and game folders are generated by the Godot web export ("Web Viewer" and "Web Game" presets). Do not edit them by hand.
